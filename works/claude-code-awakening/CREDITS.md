# Claude Code · 光标唤醒 · 来源与署名

版本：1.0.0。作者与发布者：MingoYung。描述：终端光标唤醒Clawd，柔性光丝接入铜棕发编程学者；22秒，含脚步、流光与欢迎语。

## 本项目与品牌贡献

- 官方 CLI 像素 Clawd 形状与原生 default/look-right/arms-up 姿势，忠实转录自 `@anthropic-ai/claude-code` `2.1.177`，没有把 Claude 通用 asterisk 冒称为 Code 独有标志。Anthropic 名称、品牌与 Clawd 图形保留权利，CLI 许可并非 MIT 品牌素材授权。
- 默认 CLI 真彩色为 RGB(215,119,87)/#D77757；本片的象牙、深炭、暖铜辅助配色及程序动效为本项目设计。
- 铜棕发、侧辫与象牙衬衣的成年编程学者由 image_gen 辅助设计，是本项目同人角色，不是 Clawd 的官方拟人形态或 Anthropic 官方形象。
- 尾段为 Seedance 2.0 Fast 第001次选用结果，经过温暖流光调色，音频包保持一致。程序片头为修订三：光标唤醒、自然微重心、整组衬线字标与柔性光丝；`generatedTailTrial=001` 和 `compositionRevision=3` 表示不同制作阶段，不代表第三次模型生成。
- 原创脚步、短促光标与流光音效沿用已验证的 v2 WAV。尾段合成欢迎语为“欢迎回来”；没有拼接旧版他人欢迎视频。动作参考为本项目 DeepSeek005。
- 工程归档可离线重建完整片，验证结果与本次 MP4 逐字节相同。归档中创建当时的 local-ready 状态是制作记录；本发布页是当前版本说明。
