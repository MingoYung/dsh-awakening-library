# DeepSeek 1.0.0 程序源码快照

这份快照只包含本项目程序前段、DeepSeek Harness 原始品牌几何和选用尾段的精确提示词。`source-manifest.json` 记录每份源码的 SHA256，以及为配合已选用成片而修正的右侧光流绘制顺序。

`assets/brand.js`、`animation.js` 与 `morph.js` 按该顺序加载，可用 `new DSHAwakening.Renderer(canvas)` 及 `render(time)` 检查前段。建议画布使用 1920×1080，成片则编码为 1280×720。源码保留通用播放器接口，但此快照没有旧版第三方欢迎视频或旧角色原声音轨。

本次完整影片的尾段是项目重新生成的 Seedance 2.0 Fast 第005条结果，并在14秒处接入；完整成片见该作品固定版本 MP4。此快照不是完整的可确定重建工程，不能承诺重新运行生成模型得到相同人物像素。
